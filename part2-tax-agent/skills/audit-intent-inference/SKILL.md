# 税审问题意图识别 Skill

## 使用时机

当税审问题带有“能否、是否、为什么、需要什么材料、风险是什么”等质询语气时使用本 skill。

## 数据来源

- `refs/intent-taxonomy.json`
- 数据标记为 `demo_seed`，仅用于 POC 演示。

## 输出要求

1. 只能输出“可能意图”或“假设”，不得断言用户真实意图。
2. 每个意图给出触发词和置信度。
3. 至少给出一个替代解释或说明为什么无替代解释。
4. 明确需要反问或补证的事实。

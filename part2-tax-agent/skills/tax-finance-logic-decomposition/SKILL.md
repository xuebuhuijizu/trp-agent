# 税务/财务逻辑拆解 Skill

## 使用时机

当问题需要解释税务或财务逻辑链时使用本 skill，尤其是问题中出现增值税、企业所得税、进项税额、发票、收入确认、成本费用、纳税调整等术语时。

## 数据来源

- `refs/terms.json`
- 数据标记为 `demo_seed`，仅用于 POC 演示，不是权威税务词库。

## 输出要求

1. 列出命中的术语和匹配文本。
2. 说明术语所属类别。
3. 拆出税务逻辑链：主体、交易、税种、时间、金额、凭证、风险。
4. 列出待确认事实，不直接假设缺失事实。
5. 后续回答必须保留术语命中依据。

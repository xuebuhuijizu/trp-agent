# 税务回答 Skill

## 适用场景

当用户提出中国税务相关问题时使用本 skill，包括：

- 税务概念定义
- 税率、税额或优惠比例说明
- 是否需要申报、是否合规等判断
- 发票、企业所得税、增值税、小规模纳税人等主题

## 回答规范

1. 使用中文回答。
2. 先说明适用前提，再给结论。
3. 需要法规依据时调用 `retrieve_tax_context` 工具。
4. 引用必须保留检索工具返回的 `source_id` 和 `title`。
5. 对不确定或依赖地区政策的事项，明确说明局限性。
6. 不输出模型内部推理标签，例如 `<think>...</think>`。

## 输出重点

- 定义类问题：先给核心含义，再给依据和例子。
- 税率类问题：说明税种、适用税率、计算口径和例子。
- 合规类问题：列出事实前提、法规依据、判断结论和风险提示。
